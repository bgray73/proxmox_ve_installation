# Agents

Optional companion services for the Proxmox home-lab stack.

| Path | Description |
|------|-------------|
| [`labops-a2a/`](labops-a2a/) | Demo [A2A](https://a2a-protocol.org) (Agent2Agent) status agent with SQLite persistence and Docker packaging |

These are **not** required for PVE/PBS installation. They illustrate multi-agent interoperability patterns for LabOps tooling.
